## Project description

I just wanted to open a file.

An Aadhaar Offline eKYC package can arrive as an encrypted ZIP containing an XML document with identity information, address, a portrait, hashes and reference data. Reading it should not require surrendering the file to another website.

So I built eKYC Viewer.

The product is intentionally small: select the ZIP or XML, unlock it locally when necessary, read the identity record, and clear the session when finished.

There is no document upload, account, database, analytics layer or server-side parsing. The interface is designed around the same principle as the implementation: the document stays on the device.

The project became an exploration of privacy-first UX, information hierarchy, sensitive-data disclosure, mobile interaction, local file processing and the difference between parsing a document and verifying it.
