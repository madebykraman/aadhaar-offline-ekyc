Private by architecture.
01
The file stays here

02

03

Project notes
A better way to open one file.
Offline eKYC is useful, but its native format asks ordinary people to navigate an encrypted ZIP and raw XML. The product problem was small and very real: make the file legible without asking for more trust than necessary.
Constraint
Personal identity data must not leave the device.
Decision
One-purpose, client-only PWA with no API surface.
System
Calm hierarchy, deliberate disclosure, and a clear exit.
Outcome
A portable utility that makes the hidden information readable.
